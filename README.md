# 🛡 X 评论城管 (X Comment Police Officer)

一个 X/Twitter 浏览器扩展：自动过滤评论区里的垃圾广告与骚扰评论，让它们**彻底消失，不留痕迹**。

## 用途

在 X/Twitter 评论区，经常会有批量注册的垃圾账号发布广告、钓鱼内容，试图把用户引流到站外。本插件自动识别并隐藏这些评论：

- **广告与骚扰评论**：自动隐藏，不占版面、不留空隙
- **钓鱼诱导**：识别"求关注/引流/私聊"等诱导话术与谐音、变体、emoji 拆词等绕过手法
- **广告昵称**：昵称本身是广告的账号，其全部评论直接屏蔽（支持 emoji 拆词昵称）
- **防误杀**：正常讨论（游戏用语、食物口感、宠物玩笑、护肤话题等）不会误伤

所有检测都在**本地浏览器**内完成，评论内容**不会上传到任何服务器**。

## 功能

| 功能 | 说明 |
|---|---|
| 多信号加权评分 | 多种信号叠加计分，达到阈值即隐藏，可调灵敏度 |
| 变形识别 | 去 emoji、去空格后匹配，拆词/谐音/插符号都能抓住 |
| 昵称硬过滤 | 广告类昵称（含非法商品、引流等无歧义词）直接屏蔽 |
| 话题抑制 | 主推文本身在讨论某话题时，评论区相关讨论不误杀 |
| 重复刷屏检测 | 相同内容反复出现的评论自动加权 |
| 审查模式 | 不隐藏、只半透明显示，方便观察判定是否合理 |
| 误杀恢复 | 弹窗列出最近过滤的评论，一键恢复显示 |
| 在线试词 | 设置页粘贴任意文本，实时查看命中分数与原因 |

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 打开右上角**开发者模式**
3. 点击**加载已解压的扩展程序**，选择本项目目录
4. 打开任意 X 页面（`x.com`），点工具栏 🛡 图标确认已启用

## 使用

- **工具栏图标**：开关过滤 / 查看本页过滤数量 / 最近过滤列表（可恢复误杀）
- **图标角标**：当前页面已过滤条数
- **设置页**：灵敏度阈值、白名单/黑名单、自定义关键词、导出导入配置、在线试词

### 建议

- 初次使用可先开启「审查模式」观察几天，确认判定合理后切换为「彻底隐藏」
- 遇到漏网的评论，可在设置页「钓鱼话术」分类中添加自定义关键词
- 阈值越低越激进（更容易漏网→误杀），默认值经过调校，一般无需改动

## 隐私

- 所有分析完全在本地浏览器内完成，不收集、不上传任何浏览数据
- 唯一的可选网络请求是「主页深查」功能读取作者公开主页信息（仅对边界分值评论触发、限速、失败自动跳过，可在设置中关闭）
- 设置保存在 Chrome 同步存储，仅用于同步你的偏好

## 开发

```bash
npm test        # 运行检测引擎单元测试（66 项：广告命中 + 正常评论防误杀 + 话题抑制 + 昵称过滤）
npm run icons   # 重新生成图标
```

## 目录结构

```
manifest.json        # MV3 清单
src/config.js        # 规则库：关键词/正则/权重/默认配置
src/engine.js        # 检测引擎（纯逻辑，浏览器/Node 通用）
src/content.js       # 评论区监听与隐藏
src/background.js    # 角标统计
src/popup.*          # 弹窗
src/options.*        # 设置页 + 试词
test/engine.test.js  # 单元测试
scripts/gen_icons.py # 图标生成
```
