# 🛡 X 评论城管 (X Comment Police Officer)

把 X/Twitter 评论区里的招嫖广告、色情引流和钓鱼评论**彻底干掉**——它们被隐藏后不留任何空隙，就像从未存在过。

针对的典型内容（真实案例）：

| 评论 | 识别信号 |
|---|---|
| 应该没人比我玩的开了吧🥑🤓我福不黑不信你看 | 「玩的开」+「福不黑」谐音钓鱼 + emoji 干扰 |
| 比我好看的没我骚🤏🚴比我骚的没我好看 | 「比我骚」自称擦边 |
| 我果然太涩了🌤️🍝有人想锐评一下我的福嘛 | 「我…太涩」+「锐评…福」谐音钓鱼 |
| 加微信 138xxxx8888 全套300包夜800 | 招嫖词 + 价格 + 手机号 |

## ✨ 功能

- **多信号加权评分**：招嫖交易词(100) / 色情广告词(50) / 联系方式(25) / 钓鱼话术(14) / 诱导话术(8)，分数达到阈值即隐藏
- **变形绕过识别**：去 emoji、去空格后匹配——`我 福 不 黑`、`玩 的 开`、`吧🥑我` 都能抓住
- **话题抑制**：主推文本身在聊嫖娼新闻（如李易峰嫖娼事件）时，评论区正常讨论该话题**不会被误杀**
- **上下文防误杀**：`这波操作太骚了`(游戏) / `这个柿子太涩了`(食物) / `我家猫太骚了`(宠物) / `我有福气` / `看我的皮肤状态` / `微信公众号` 均不命中
- **账号信号**：昵称/ID 敏感词、重复刷屏检测、边界分值评论拉取作者主页简介复核（保守限速，失败静默）
- **误杀恢复**：弹窗列出最近过滤的评论，一键恢复显示
- **审查模式**：不隐藏而是半透明显示，方便你检查判定是否合理
- **在线试词**：设置页粘贴任意文本，实时显示分数和命中原因

## 📦 安装（加载已解压的扩展程序）

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 打开右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择本项目目录（含 `manifest.json` 的 `x-comment-police-officer` 文件夹）
4. 打开任意 X 页面（`x.com`），点工具栏 🛡 图标确认已启用

> 也可以先去设置页（插件图标 → ⚙ 设置）→「在线试词」，把你的真实评论贴进去看看判定结果。

## 🎛 使用

- **工具栏图标**：开关过滤 / 查看本页过滤数量 / 最近过滤列表（误杀可恢复）
- **图标角标**：当前页面已过滤条数
- **设置页**：灵敏度阈值、白名单/黑名单、关键词管理（自定义词按分类加权重）、导出导入配置

### 推荐配置

- 评论区阈值默认 **14**：一条高置信钓鱼话术（如「我福不黑」14 分）即可隐藏
- 若误杀变多：阈值调到 16~18，或开启**审查模式**观察一段时间
- 若漏网变多：阈值调到 10~12，或在「钓鱼话术」分类下补充你看到的变体词

## 🧠 原理

1. 内容脚本运行在 x.com，通过 `MutationObserver` 监听评论区 DOM（`article[data-testid="tweet"]`）
2. 每条评论抽取 文本/昵称/ID → 引擎评分（纯本地计算）
3. 分数 ≥ 阈值 → 加 `display:none !important` 类并定时补刀（防 React 重渲染覆盖）
4. 主题抑制：解析当前线程主推文命中的词，评论里出现同样词时不重复计分
5. 统计写入扩展存储，弹窗/角标展示

## 🔒 隐私

- 所有分析**完全在本地浏览器内**完成，评论内容**不会上传到任何服务器**
- 唯一网络请求是「主页深查」功能读取作者公开主页简介（仅边界分值评论触发，限速 15 次/分钟，失败自动跳过；可在设置中关闭）
- 设置保存在 Chrome 同步存储，仅用于同步你的偏好

## ⚠️ 说明

- 过滤基于启发式规则，**存在误杀可能**。强烈建议先开「审查模式」用几天，误杀点「恢复」并加入白名单
- X 前端改版可能导致选择器失效，届时插件会静默失效（不影响浏览），欢迎提 issue
- 本插件不拦截私信、不举报账号，只负责眼不见心不烦

## 📁 结构

```
manifest.json        # MV3 清单
src/config.js        # 规则库：关键词/正则/权重/默认配置
src/engine.js        # 检测引擎（纯逻辑，浏览器/Node 通用）
src/content.js       # 评论区监听与隐藏
src/background.js    # 角标统计
src/popup.*          # 弹窗
src/options.*        # 设置页 + 试词
test/engine.test.js  # 单元测试
scripts/gen_icons.py # 图标生成
```
